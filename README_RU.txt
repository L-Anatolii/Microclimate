Проект Microclimate для VS Code + PlatformIO

1. Распакуйте архив.
2. В VS Code выберите File -> Open Folder и откройте папку Microclimate_PlatformIO.
3. Установите расширение PlatformIO IDE, если оно ещё не установлено.
4. Дождитесь инициализации PlatformIO.
5. Сначала нажмите Build (галочка), не подключая плату.
6. Если сборка успешна, подключите ESP32, выберите COM-порт и нажмите Upload (стрелка).

Что перенесено:
- исходный скетч ui.ino -> src/main.cpp (добавлен #include <Arduino.h>);
- LVGL 8.3.11;
- исходный lv_conf.h -> include/lv_conf.h;
- TFT_eSPI, RTClib, Adafruit BusIO и SquareLine UI сохранены как локальные библиотеки в lib/;
- оригинальный TFT_eSPI/User_Setup.h оставлен без изменений.

ВАЖНО ПО ПОДКЛЮЧЕНИЮ:
В исходном User_Setup.h выбран ST7789. Активные настройки ESP32:
MOSI=23, SCLK=18, CS=5, DC=2, RST=4, BL=22.
Также определён M5STACK. Эти настройки сохранены как в исходном архиве.
Скетч вызывает Wire.begin(21, 22) для RTC DS3231. При этом GPIO22 одновременно
указан как TFT backlight. Проверьте фактическое подключение: возможно, здесь
есть конфликт пинов. Пока ничего не меняйте.

Сначала выполните Build. Если будет ошибка, пришлите сюда весь первый блок ошибки
из терминала PlatformIO. Оригинальный проект Arduino IDE не удаляйте.
